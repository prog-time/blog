## Описание

Для проекта **Postery** был разработан сайт с промо-страницей и документацией.
Сайт собран на VitePress, блоки главной страницы написаны как Vue-компоненты.
Исходный код лежит в репозитории [prog-time/postery-docs](https://github.com/prog-time/postery-docs),
деплой на GitHub Pages идёт через GitHub Actions.
