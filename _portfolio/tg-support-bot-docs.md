## Описание

Для проекта **TG Support Bot** был разработан отдельный сайт документации.
Он собран на VitePress: весь контент хранится в Markdown в репозитории
[prog-time/tg-support-bot-docs](https://github.com/prog-time/tg-support-bot-docs),
а публикация идёт автоматически через GitHub Actions.

Сайт доступен на двух языках — русском и английском, со встроенным поиском
по обеим версиям и автоматической генерацией sitemap.
